🚀 安装步骤

ℹ️ 请在 PowerShell 中逐步执行以下命令
激活虚拟环境后，所有 Python 依赖将隔离在 rembg_env 目录中，不会影响其他项目。

第一步：进入项目目录

cd D:\Bili-Daily

第二步：创建虚拟环境

py -m venv rembg_env

第三步：激活虚拟环境

.\rembg_env\Scripts\Activate.ps1

成功标志：提示符变为 (rembg_env) PS>

第四步：升级 pip

python -m pip install --upgrade pip

第五步：安装 rembg 和 isnet-anime

python -m pip install "rembg[cpu,cli]"

⏱️ 预计时间：2-5 分钟 | 📊 下载大小：300-400 MB

第六步：下载动漫分割模型

python -c "from rembg import new_session; session = new_session('isnet-anime'); print('Model loaded!')"

⏱️ 首次下载：1-5 分钟 | 📊 模型大小：200-400 MB

模型保存位置：C:\Users\39496\.rembg\models\isnet-anime\

💡 使用示例

命令行使用

# 激活虚拟环境 .\rembg_env\Scripts\Activate.ps1 # 处理单个图像（isnet-anime 动漫模型） rembg -m isnet-anime -i neo-images/NEO.png -o output/NEO_transparent.png # 批量处理（所有 PNG 文件） foreach($file in Get-ChildItem neo-images/*.png) { rembg -m isnet-anime -i $file -o "output/$($file.BaseName)_transparent.png" }
