## 一、设计方向

### 主题定位
**NEON DREAM / 赛博二次元**  
高完成度日系科幻游戏 HUD + 原创动漫角色 + 沉浸式霓虹个人终端

### 视觉参考
- ✅ 日系科幻游戏界面（《13 Sentinels》、《AI: The Somnium Files》、《Nier》系 HUD）
- ✅ 高品质原创二次元角色立绘 + 半透明全息投影质感
- ✅ 明确视觉焦点、层次清晰、柔和体积光、玻璃材质
- ❌ 拒绝：普通后台管理界面、堆砌矩形卡片、廉价渐变、过度描边

### 色彩方案
**主色调**: 午夜蓝 `#0A0E1C`、深空蓝 `#0F1828`、深紫 `#1A1230`  
**强调色**: 
- 冰蓝霓虹 `#5CF2FF` (主要交互)
- 紫罗兰 `#9B7BFF` (数据可视化)
- 洋红霓虹 `#FF4FD8` (次要强调，克制使用)
- 柔和金 `#FFC46B` (警告/特殊状态)

**透明度分层**:
- 背景基础层 `opacity: 1`
- 玻璃卡片 `rgba(10, 17, 33, 0.85)` + `backdrop-filter: blur(12px)`
- 悬浮元素 `rgba(16, 26, 48, 0.95)` + `backdrop-filter: blur(16px)`

## 二、原创角色 NEO

### 角色设定
**全名**: NEO (Neural Echo Observer)  
**身份**: Bili Daily 虚拟助手 · 个人数据观察者  
**人设**: 未来科技世界观中的二次元少女，温和、专注、可靠

### 外观设计方向
- **发色**: 银白偏浅紫，长直发，部分发束带有半透明全息效果
- **瞳色**: 霓虹蓝紫渐变，眼神温和但有科技感，瞳孔可能有环形数据流装饰
- **服饰**: 未来科技风格，深色底衣 + 发光线条装饰，非紧身，强调科技感而非性感
- **配件**: 单侧耳机式通讯器，手部或颈部可能有全息投影手环/项圈

### 使用场景
1. **Dashboard 完整仪表盘**: 半身立绘（肩部以上或腰部以上），放置在页面右上或右侧，作为视觉焦点
2. **Edge popup**: 圆形或方形小头像（64×64 或 80×80px），保留标志性发色和眼神特征

### 动画规划
- **待机**: 轻微呼吸动画（2-3s 循环，上下浮动 2-4px）
- **眨眼**: 自然眨眼（每 4-7 秒随机触发，100ms 闭眼）
- **交互反馈**: 点击时轻微缩放或发光 (scale 1.02 + glow pulse)
- **数据更新**: 眼睛周围出现短暂的环形扫描线效果

## 三、双界面布局

### A. Edge Popup (420×640px max)
**定位**: 轻量日常入口，快速查看昨日统计

**信息架构**:
```
┌─────────────────────────────────────┐
│ HEADER: NEO 小头像 + 品牌标识      │ 80px
├─────────────────────────────────────┤
│ 昨日观看总结卡片                   │ 180px
│ ├ 视频数 / 时长 (大字号)          │
│ ├ 主要分区 (图标 + 文字)          │
│ └ TOP UP 主 (头像列表)            │
├─────────────────────────────────────┤
│ 快速操作区                         │ 100px
│ ├ [打开完整仪表盘] 主按钮         │
│ └ [刷新推荐] 次按钮               │
├─────────────────────────────────────┤
│ 7 天兴趣雷达图（紧凑版）           │ 160px
├─────────────────────────────────────┤
│ 今日推荐（折叠，显示 1-2 条）      │ 120px
└─────────────────────────────────────┘
```

**视觉特征**:
- 深色半透明背景 + 细微网格纹理
- NEO 头像置于右上角，带呼吸动画
- 昨日卡片使用玻璃毛玻璃材质，淡蓝色发光边框
- 主按钮大而显眼，用霓虹蓝填充 + 悬停发光
- 雷达图使用 SVG，填充紫色渐变，描边冰蓝

### B. Dashboard 完整仪表盘 (独立扩展页面)
**打开方式**: 点击 popup 主按钮，或右键扩展图标选择

**页面布局** (1200×900px 参考，响应式):
```
┌────────────────────────────────────────────────────────────┐
│ TOP NAV: 品牌 LOGO + 导航 tabs + NEO 立绘(右上)          │ 100px
├────────────────────────────────────────────────────────────┤
│ HERO SECTION: 大型昨日回顾 + 动态背景                    │ 280px
│ ├ 左侧: 统计数字 (巨大字号，发光效果)                   │
│ └ 右侧: NEO 半身立绘 + 语音气泡(可选)                    │
├────────────────────────────────────────────────────────────┤
│ ┌─────────────────────┬────────────────────────────────┐  │
│ │ 观看时间轴          │ 7 天兴趣画像（大型雷达图）    │  │
│ │ (横向滚动卡片)      │ + 维度柱状图                  │  │
│ │ 240px               │ 360px                          │  │
│ └─────────────────────┴────────────────────────────────┘  │
├────────────────────────────────────────────────────────────┤
│ UP 主排行榜 (网格布局，3-4 列，头像 + 昵称 + 数据)       │ 280px
├────────────────────────────────────────────────────────────┤
│ ┌──────────────────────────┬───────────────────────────┐  │
│ │ 今日推荐 (5 张卡片)     │ 自动发现 (候选列表)      │  │
│ │ 纵向排列，大卡片         │ 紧凑列表 + 控制按钮      │  │
│ │ 500px                    │ 340px                     │  │
│ └──────────────────────────┴───────────────────────────┘  │
├────────────────────────────────────────────────────────────┤
│ 候选导入 & 数据舱 (折叠面板，默认收起)                    │ auto
└────────────────────────────────────────────────────────────┘
```

**视觉特征**:
1. **背景**: 深色渐变 + 柔和径向光晕（冰蓝/紫色，低透明度）+ 细微粒子动画
2. **NEO 立绘**: 右上角固定，PNG 透明背景，尺寸约 300×500px，带发光轮廓和呼吸动画
3. **玻璃卡片**: 半透明背景 + 毛玻璃效果 + 1px 霓虹描边 + 内阴影
4. **数据可视化**: 使用 D3.js 或 Canvas 绘制，避免使用外部 CDN
5. **转场动画**: 卡片进入时带淡入 + 上移(20px)，duration 400ms，ease-out
6. **悬停效果**: 卡片轻微上浮(4px) + 阴影加深 + 边框发光增强

## 五、设计系统规范

### 排版
**字体族**:
- 主体: `"Noto Sans SC", "Microsoft YaHei", "PingFang SC", sans-serif`
- 数字/代码: `"JetBrains Mono", "Cascadia Code", Consolas, monospace`
- 标题: `"Noto Sans SC", -apple-system, sans-serif` (加粗)

**字阶**:
```css
--text-xs:   12px / 1.4  /* 脚注、标签 */
--text-sm:   14px / 1.5  /* 正文辅助 */
--text-base: 16px / 1.6  /* 正文 */
--text-lg:   18px / 1.5  /* 小标题 */
--text-xl:   24px / 1.3  /* 卡片标题 */
--text-2xl:  32px / 1.2  /* 页面主标题 */
--text-3xl:  48px / 1.1  /* Hero 数字 */
--text-4xl:  64px / 1    /* 大型 Hero */
```

### 间距
**8px 基础网格**:
```css
--space-1:  4px
--space-2:  8px
--space-3:  12px
--space-4:  16px
--space-5:  24px
--space-6:  32px
--space-8:  48px
--space-10: 64px
```

### 圆角
```css
--radius-sm: 4px   /* 按钮、输入框 */
--radius-md: 8px   /* 小卡片、标签 */
--radius-lg: 16px  /* 主要卡片 */
--radius-xl: 24px  /* Hero 区域 */
--radius-full: 9999px /* 圆形头像、徽章 */
```

### 阴影
```css
--shadow-sm: 0 2px 8px rgba(0, 0, 0, 0.3);
--shadow-md: 0 4px 16px rgba(0, 0, 0, 0.4);
--shadow-lg: 0 8px 32px rgba(0, 0, 0, 0.5);
--shadow-glow-cyan: 0 0 20px rgba(92, 242, 255, 0.3);
--shadow-glow-magenta: 0 0 20px rgba(255, 79, 216, 0.3);
```

### 动画时长
```css
--duration-fast: 150ms
--duration-base: 300ms
--duration-slow: 500ms
--easing-standard: cubic-bezier(0.4, 0.0, 0.2, 1)
--easing-decelerate: cubic-bezier(0.0, 0.0, 0.2, 1)
--easing-accelerate: cubic-bezier(0.4, 0.0, 1, 1)
```

### 无障碍
- 所有交互元素 `min-height: 44px`
- 色彩对比度 ≥ 4.5:1 (正文), ≥ 3:1 (大文本)
- 支持 `prefers-reduced-motion` 禁用装饰动画
- 键盘导航: 所有按钮、链接可通过 Tab 访问，焦点环明显
- 屏幕阅读器: 装饰元素添加 `aria-hidden="true"`，动态内容使用 `aria-live`

## 六、技术实现约束

### 框架与依赖
- **禁止**: React / Vue / Angular / 远程 CDN
- **允许**: 原生 Web Components / 轻量级工具库(本地打包)
- **可视化**: 优先使用 Canvas / SVG 原生绘制，如需库则使用 D3.js v7 离线版本

### 性能目标
- 首次渲染 < 300ms (模拟数据)
- 卡片动画 60fps
- 资源总大小 < 2MB (包含字体、图片、JS/CSS)

### 兼容性
- Edge 浏览器 (Chromium 110+)
- Windows 11
- 1920×1080 分辨率及以上

## 八、设计理念总结

### 为什么要重构？
现有 UI 是功能优先的快速 MVP，缺乏视觉层次和情感连接。用户每天打开扩展时，应该感受到的是一个精心设计的个人数据终端，而不是一个普通的设置面板。

### NEON DREAM 的核心
1. **角色存在感**: NEO 不是装饰，是用户的数据伙伴
2. **信息层次**: 重要数据大而明显，次要信息收起或弱化
3. **高级感**: 通过材质、光影、细节动画体现品质
4. **克制**: 不过度使用霓虹色，留白和深色区域占大部分面积
5. **中文优先**: 所有 UI 文案、标签、数据都是中文，排版适配中文阅读

### 设计不妥协的地方
- ❌ 不用简单几何形状冒充角色立绘
- ❌ 不用纯色矩形堆砌代替精心设计的卡片
- ❌ 不用粗暴的渐变和描边掩盖设计缺失
- ❌ 不为了"简洁"隐藏用户需要的功能
