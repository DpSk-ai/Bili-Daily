# Bili Daily v1.1 Neon Edition · 视觉与交互设计规范

- 版本：v1.1
- 日期：2026-11-12
- 状态：已按本规范实现，待自动化测试与 Edge 真实验收
- 范围：仅扩展弹窗（`popup.html` / `popup.css` / `popup.js`）与本地原创 SVG 素材
- 不改变：观看采集、兴趣画像、推荐算法、自动发现准入、导入校验规则

---

## 1. 设计概念

**Neon Archive / 霓虹档案**

把弹窗设计成一台“个人观看档案终端”：深色舱体、青色数据链路、品红色警报与探索标记，
右上角是一位原创的全息助手「NEO-01」。她不是装饰贴图，而是状态提示的一部分：
助手旁边的状态灯与文案随自动发现开关、数据读取状态变化。

目标气质：

- 赛博、二次元、夜间使用舒适；
- 有明确的主色与记忆点，不是通用“蓝紫渐变 AI 仪表盘”；
- 信息密度高但不拥挤，操作按钮始终可找到；
- 动效服务于状态反馈，不做无意义的持续闪烁。

明确避免：

- 大面积纯黑 + 单一紫色渐变；
- 圆角卡片堆叠、彩色发光按钮的通用模板感；
- 第三方动漫角色、游戏角色或任何已有 IP 的临摹；
- 高频闪烁、持续位移、影响阅读的动画。

使用规则：

- 青色用于“本地、已连接、主操作”；品红用于“探索、陌生、注意”；琥珀用于“数据不足/警告”。
- 同一卡片最多两个强调色；正文不使用高饱和色。
- 颜色不能作为唯一状态信号：状态同时用文字（已开启/已关闭/数据不足）表达。
- 正文对比度不低于 4.5:1；10–11px 辅助文字只用于非关键信息。

## 3. 字体与排版

- 中文正文：`"Segoe UI", "Microsoft YaHei", "PingFang SC", sans-serif`
- 数字与标签：`Consolas, "Cascadia Code", monospace`
- 标题：`Bili Daily` 使用 700 字重、轻微字距；副标题使用大写/半角混排的终端标签。
- 字号阶梯：
  - 弹窗标题 22px / 24px
  - 卡片标题 12px（终端标签风格，字距 0.12em）
  - 主数值 18–20px
  - 正文 12.5px
  - 辅助 10.5–11px
- 行高：正文 1.55；紧凑元信息 1.4。
- 不使用外部字体，避免网络请求与首屏闪烁。

---

## 4. 布局

- 弹窗宽度：**420px**；最大高度：**640px**，内部纵向滚动。
- 外边距：14px；卡片间距 10px；卡片内边距 12–14px。
- 顶部为「驾驶舱」头部：
  - 左侧：几何 Logo + `BILI DAILY` + `NEON EDITION // LOCAL ONLY`
  - 右侧：原创助手 `NEO-01` 半身像 + 状态灯
- 头部下方为一条 1px 数据分隔线，带渐变与扫描光点。
- 主体卡片顺序保持不变：昨日总结 → 兴趣画像 → 今日推荐 → 自动发现 → 候选导入 → 数据舱。
- 底部状态栏：`LOCAL STORAGE · NO UPLOAD · v1.1`。

### 4.1 卡片结构

每张卡片采用 HUD 面板：

- 1px 青色/品红边框，左上与右下有 L 形角标（`::before`/`::after`）。
- 背景为半透明深色，叠加极细网格（CSS `linear-gradient`），不使用位图。
- 卡片标题左侧有一条 3px 竖线或短横线，颜色随卡片主题。
- 卡片进场：透明度 + 6px 上移，200–320ms；同屏卡片最多 80ms 级联。
- 推荐卡与导入批次可悬停抬升 1px，边框增亮；不做强烈缩放。

## 5. 组件

### 5.1 状态胶囊

- 形状：小圆角矩形（8px），不是全圆角药丸。
- 结构：左侧 5px 状态点 + 文本。
- 颜色：青色=已启用/就绪；品红=探索；琥珀=数据不足；灰=关闭；红=错误。

### 5.2 数据瓦片

- 2 列或 3 列网格，数字使用等宽字体。
- 背景为深色，右侧/底部有细青色刻度线。
- 数字变化不做滚动动画，避免闪烁。

### 5.3 画像条

- 轨道 5px；填充为青色→品红渐变。
- 进入时从左展开 500ms；`prefers-reduced-motion` 下直接显示。
- 标签过长省略号，数值右对齐。

### 5.4 推荐卡

- 主通道：青色左边线 + `回访推荐` 标签。
- 探索通道：品红左边线 + `探索推荐` 标签。
- 页面观察候选额外显示 `PAGE-OBSERVED` 微型标签。
- 推荐理由使用 `▸` 前缀；最多 3 条，超出由服务层截断。
- UP 主名称可点击时使用虚线下划线，`rel="noopener noreferrer"`。

### 5.5 按钮

- 主按钮：青色渐变边框 + 深色底，悬停提高亮度；不使用大面积实心亮色。
- 次按钮：透明底 + 细边框。
- 危险按钮：品红/红色边框与文字。
- 所有按钮 `:focus-visible` 有 1px 青色轮廓，键盘可操作。
- 禁用态透明度 0.5，保留布局。

### 5.6 数据舱（v1.1 新增）

- 位置：候选导入之后、页脚之前。
- 标题：`数据舱 · 本地备份`
- 说明：只导出/恢复四个本地键；导入前预览；不改变权限；不上传。
- 操作：
  - `导出全部数据`：生成 `bili-daily-backup-YYYYMMDD-HHMMSS.json`
  - `选择备份文件`：最大 5 MiB，格式 `bili-daily-backup` v1
  - 预览区：显示观看天数/记录数、导入批次数、观察条数、设置状态
  - `确认恢复` / `取消`
- 危险提示：确认恢复会覆盖备份中包含的同名键；未包含的键保持不变。

## 6. 原创助手 NEO-01

### 6.1 定位

原创全息助手，仅在弹窗头部出现，不参与推荐决策，不冒充平台官方角色。

### 6.2 造型

- 半身像，240×240 SVG，透明背景。
- 深蓝黑短发 + 青色发光发梢；左耳机械耳机；青色面罩/眼线；高领外套；品红导线。
- 周围有 2 圈全息环与 3 个数据刻度，形成“终端助手”识别点。
- 线条硬朗、几何化，避免临摹任何现有动漫角色。
- 不使用真实人物照片、不生成带第三方 IP 的素材。

### 6.3 动态

- 全息环缓慢旋转（12s/18s，反向）。
- 面罩高光 4s 呼吸。
- 状态灯：绿色=本地存储正常；青色=自动发现开启；品红=有页面观察候选；灰色=关闭。
- 所有动画只用 `transform` / `opacity`，避免布局抖动。
- `prefers-reduced-motion: reduce` 下停止旋转与呼吸，只保留静态高光。

### 6.4 降级

- SVG 加载失败时显示 CSS 几何替身（圆形头像框 + `NEO-01` 文本）。
- 不依赖网络或外部字体。
- 图片带 `alt="NEO-01 全息助手"`，装饰性环使用 `aria-hidden`。

## 7. 动效规范

| 动效 | 时长 | 缓动 | 说明 |
|---|---:|---|---|
| 卡片进场 | 260ms | `ease-out` | 透明 + 6px 上移 |
| 按钮悬停 | 150ms | `ease` | 亮度/边框 |
| 推荐卡悬停 | 180ms | `ease` | 上移 1px + 阴影 |
| 画像条展开 | 500ms | `ease-out` | `scaleX` |
| 扫描线 | 7s | `linear` | 单条，低透明度，循环 |
| 全息环 | 12s/18s | `linear` | 反向旋转 |
| 状态灯呼吸 | 3.2s | `ease-in-out` | 透明度 0.6→1 |

约束：

- 不使用高频闪烁（≤3 Hz 为安全上限，本设计远低于）。
- 页面隐藏时浏览器会自动节流；不额外使用 JS 动画循环。
- 不使用会触发 layout 的 `width/height/top/left` 动画。
- 同屏持续动画元素不超过 6 个。

---

## 8. 可访问性

- 所有交互控件保留原生 `button` / `label` / `input`。
- 焦点顺序与视觉顺序一致；不设置正数 `tabindex`。
- `:focus-visible` 清晰可见。
- 状态文本使用 `aria-live="polite"` 的区域继续保留。
- 颜色对比：主文本 ≥ 4.5:1；大数字 ≥ 3:1。
- `prefers-reduced-motion: reduce` 时禁用所有动画与过渡。
- 放大到 200% 时允许纵向滚动，不出现横向滚动。

---

## 9. 性能预算

- 不引入外部字体、图片 CDN、动画库或框架。
- 仅新增 1 个本地 SVG（压缩后 < 20 KB）。
- 背景网格与光晕使用 CSS 渐变，不新增位图。
- 动画只使用 `transform` / `opacity`；避免对大面积元素做 `filter: blur` 动画。
- 弹窗打开到首屏可读目标 < 500ms（本地数据、无网络）。
- 新增 JS（`data-backup.js`）保持纯函数、无网络、无 DOM 依赖。

---

## 10. 验收要点

1. 420px 宽度下无横向滚动；长 UP 名/长标题省略显示。
2. 六个卡片层次清晰，标题、状态、操作按钮在 3 秒内可定位。
3. 助手 SVG 可见、动画流畅；关闭动画后布局不变。
4. 推荐卡的主/探索通道颜色区分明显，来源标签可读。
5. 数据导出能生成 JSON；导入能预览、取消、确认，失败不覆盖旧数据。
6. 键盘可完成刷新、开关自动发现、导入候选、导出/恢复数据。
7. `prefers-reduced-motion` 下无持续旋转/呼吸动画。
8. 与 v1.0 功能一致：观看统计、画像、推荐、自动发现、导入均可用。

---

## 11. 非目标

- 不在 v1.1 增加新的推荐算法或改变排序权重。
- 不扩大扩展权限，不申请 `host_permissions`、`downloads`、`cookies`。
- 不做完整角色动画系统、语音、在线 AI 对话。
- 不引入远程资源或遥测。
