## 素材处理方案

### 方案 A: CSS 混合模式（已采用）

**原理**: 使用 `mix-blend-mode: multiply` 让白色背景在深色页面上自然消失。

**优点**:
- 无需预处理图像
- 实时可调整
- 跨浏览器兼容
- 保持原图质量

**缺点**:
- 不是真正的透明 PNG
- 需要深色背景配合

### 方案 B: 手动裁剪（备选）

如需真正的透明 PNG，可手动操作：

**工具选择**:
1. **Paint 3D** (Windows 自带)
   - 打开 `neo-reference.png.png`
   - 使用"魔术选择"工具
   - 选中角色
   - 导出为 PNG

2. **remove.bg** (在线工具)
   - 上传 `neo-reference.png.png`
   - 自动去除背景
   - 下载透明 PNG

3. **Photoshop / GIMP**
   - 钢笔工具抠图
   - 保存为 PNG-24 (透明)

**裁剪坐标**（基于视觉估算）:

**正面立绘**（第二个角色）:
- 左边距: ~25%
- 右边距: ~48%  
- 宽度: ~23%
- 高度: 85%（从头到脚）

**头像**（左上角圆形）:
- 左边距: ~3%
- 上边距: ~3%
- 直径: ~18%
